# Contributing to plugin-empty

This is the rhdh-parasol plugin-empty playground, used for from-scratch
fullsend and software-template exercises. Contributions are welcome!

## How to propose a change

1. Fork the repository or create a branch off `main`.
2. Make your changes on the new branch.
3. Open a pull request back to `main`.

## Pull request guidelines

- Include a clear description of **what** changed and **why**.
- Link the related issue from your PR when one exists
  (e.g., `Closes #123`).
- Keep changes focused — one logical change per PR.
